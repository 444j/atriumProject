1. Open your Django Backend
Open your terminal (Command Prompt or VS Code terminal).

Navigate to your project folder:
cd C:\Users\juswa\atrium_project

(Optional) Activate your virtual environment if you use one.

Start the server:

Bash
python manage.py runserver
Keep this terminal open.

2. Open your React Frontend
Open a second terminal window.

Navigate to your frontend folder:
cd C:\Users\juswa\atrium_project\atrium-frontend

Start the React app:

Bash
npm start
This will automatically open your browser to http://localhost:3000.

3. Log In
Since we fixed the database and the code, your admin / admin12345 credentials will be waiting for you.
